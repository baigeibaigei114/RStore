# 准备并提交区域 NDVI

先在地图绘制并保存监测区域。选择一景通过 NDVI 准入的标准化影像，确保影像完整覆盖监测区。在区域 NDVI 表单选择影像和监测区，核对采集日期和范围后点击「开始分析」。

也可以进入「影像助手」，输入监测区名称和采集日期，点击「准备分析」。存在多个候选时先选择影像或区域，然后点击「去确认」进入同一表单。

## 查看结果和下载

在任务页打开对应的区域 NDVI 记录，查看有效像素比例、均值、最小值和最大值。使用「下载结果」取得 GeoTIFF。地图图层发布完成后可以在地图中查看。
