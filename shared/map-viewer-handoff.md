# 地图浏览交接

- 任务：UI-003；日期：2026-09-17；负责人：codex-map-ui。
- 左侧品牌与登录页改为“区域植被监测平台 / 遥感分析与报告”。
- MapViewerView：增加加载后自动定位、定位当前影像按钮、面板显隐与独立滚动。
- 定位读取已加载图层对应影像的 footprintWkt（EPSG:4326），转换至地图坐标系后 fit；不会因下拉选择改变而定位另一张尚未加载的影像。失效异步请求不能覆盖新图层视角。
- useOlMap：WMS 默认不透明度改为 1，增加底图可见性接口；按用户后续要求，地图页初始开启底图，用户可关闭。其他使用此 composable 的页面不主动关闭底图。
- 不修改像素、NoData 或 GeoServer 样式；透明区域使用纯色背景。
- 桌面面板避让定位视野；小屏面板移至下部，可收起。ResizeObserver 更新地图尺寸。

## 边界与后续验收

- 自动定位依赖可访问的影像详情和有效 footprint；缺失或软删除等情况提示用户，保留图层。
- 手动输入外部 WMS 尚无范围元数据，不自动定位。
- 当前按输入影像范围定位，不读取结果 WMS 的精确范围，适用于当前单期 NDVI 同网格输出。
- 浏览器验收：加载图层后自动缩放、拖动后重新定位、切换图层、收起展开、开关底图、调整不透明度、移除图层、窄屏滚动。
- 不透明度 100% 不能消除服务端样式自身的 alpha；关闭底图可避免道路和文字透出。
